# 동네카페 포인트

매일 마감 때 돌리는 포인트 적립 프로그램이에요.

## 쓰는 법

    python3 cafe.py

- 오늘 주문: data/orders.csv
- 회원 명부: data/members.csv
- 결과: out/members.csv, out/report.txt
- 키오스크 회원 화면: web/ (읽기만)

## 규칙

- 결제 금액의 1%를 포인트로 쌓아요. VIP는 3%예요.
- 누적 결제가 10만 원이 넘으면 VIP가 돼요.
- 생일이 있는 달 첫 주문에 3,000원을 깎아 줘요(5,000원 이상 주문).
- 포인트는 1,000점부터 쓸 수 있어요.

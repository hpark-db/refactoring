# CAFE-5 생일 쿠폰을 쓴 날은 포인트가 더 많이 쌓여요

| 항목 | 내용 |
| --- | --- |
| 키 | CAFE-5 |
| 유형 | 버그 |
| 상태 | 열림 |
| 보고 | 아르바이트생 |
| 만든 날 | 2026-10-17 |

> 교육용 가상 자료예요.

## 재현 순서

박노을 님(생일 10월)이 10월 17일에 9,000원을 주문했어요. 생일 쿠폰 3,000원을 깎아서 6,000원을 냈어요.

## 기대

결제 금액 6,000원의 1%인 60점이 쌓여요.

## 실제

영수증에 "적립: 90 점"이 찍혀요. 깎기 전 금액 9,000원으로 계산한 것 같아요.

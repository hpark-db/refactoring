# CAFE-1 다음 달부터 일반 회원 적립률을 1%에서 2%로 올려요

| 항목 | 내용 |
| --- | --- |
| 키 | CAFE-1 |
| 유형 | 정책 변경 |
| 상태 | 열림 |
| 보고 | 사장님 |
| 적용 날짜 | 2026-11-01부터 |

> 교육용 가상 자료예요.

## 지금

일반 회원은 결제 금액의 1%를 포인트로 쌓아요. VIP는 3%예요.

## 바꾼 뒤

일반 회원은 결제 금액의 2%를 쌓아요. VIP는 그대로 3%예요.

## 같이 바꿀 것

영수증의 "(일반 1%, VIP 3%)" 안내, 마감 보고의 적립률 줄, 키오스크 화면의 "몇 점 적립" 안내도 2%로 바꿔요.
